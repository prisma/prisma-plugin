Build with Prisma Composer, deploy to Prisma Compute, and keep your app moving forward with GitHub.

This update makes sign-in clearer and adds a guided way to save your app privately to GitHub, connect it to its existing Prisma project, and verify automatic updates from the repository's default branch.

New apps that need persistent data use Prisma Postgres through Composer. New deployments use the project's default main branch, and completed deployments include links to both your live app and its Prisma project. Existing apps keep their database choices and deployment targets.

Requires ChatGPT's desktop app with local execution. Tested on macOS. Web and cloud agent execution remain unsupported. This release does not include the deferred database connection reliability fixes.
